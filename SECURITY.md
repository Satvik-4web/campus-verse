# Security Policy

## Supported Versions
Currently, only the latest `master` branch is supported with security updates.

## Reporting a Vulnerability
If you discover any security-related issues in Campus Verse (e.g., exposed API keys, cross-site scripting vulnerabilities, or insecure dependencies), please do not disclose them publicly.

Instead, please send a direct message or open a private security advisory on this GitHub repository. 

**What to include:**
- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.

All legitimate security reports will be addressed as quickly as possible.

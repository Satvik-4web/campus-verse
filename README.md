## 🪐 The Vision: Immersive Spatial Computing
Campus Verse transcends traditional virtual tours by offering a true **Digital Twin**. Every hall, laboratory, and open quad is part of a single, continuous, highly optimized WebGL model. When you walk out of a lecture hall in Campus Verse, you step right into the quad that actually adjoins it.

<br />

## ✨ Core Features
- **Zero-Install WebGL:** Streams directly to any modern browser with absolutely no downloads, plugins, or software updates required.
- **Kiosk-Optimized:** Built from the ground up to support large touch-screen displays with native swipe gestures, hidden scrollbars, and tactile Framer Motion physics.
- **Deep Space Aesthetic:** Features a flagship Tier-1 tech startup vibe (reminiscent of Meta Reality Labs and Apple Vision Pro UIs). Deep space navy backgrounds, glowing cyan/sky-blue tech accents, and ultra-high-end glassmorphism.
- **Dynamic 3D Architecture:** Powered by `React Three Fiber`, rendering real-time interactive 3D assets that float elegantly within a bento-box UI layout.

<br />

## 🛠 Tech Stack

**Core Architecture**
- [React (v18)](https://reactjs.org/)
- [Vite](https://vitejs.dev/) - Blazing fast frontend tooling

**3D Graphics & Spatial Rendering**
- [Three.js](https://threejs.org/)
- [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction) - React renderer for Three.js
- [React Three Drei](https://github.com/pmndrs/drei) - Useful helpers and abstractions for R3F

**Styling & Animation**
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework for rapid UI styling
- [Framer Motion](https://www.framer.com/motion/) - Physics-based animation library for React
- Lucide React - Crisp, minimal vector icons

## 🚀 Getting Started

To run this project locally, make sure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Satvik-4web/campus-verse.git
   cd campus-verse
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

<br />

## 📦 Build for Production

To create an optimized production build:
```bash
npm run build
```
You can preview the built app locally using:
```bash
npm run preview
```
